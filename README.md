# WE2002-Home-Team-Editor-ML-v_0.1
Editor de estádios da Master Liga do Winning Eleven 2002 (PS1), desenvolvido em Visual Basic 6.0 por Fabio FJA. Permite configurar individualmente os estádios de 32 clubes, selecionar entre 16 opções, visualizar imagens dos estádios e modificar diretamente os arquivos BIN do jogo.
